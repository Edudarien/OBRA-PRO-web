# ObraPro V8.1 — versión estable local

Versión mejorada a partir de OBRAPRO_MOBILE_V8.

## Cómo abrir
1. Descomprime el ZIP completo.
2. No muevas archivos por separado.
3. Abre `index.html` con Chrome o Edge.
4. Los datos se guardan en el navegador de ese equipo.

## Mejoras V8.1
- Arranque más resistente: si un dato local está dañado, la app ya no debería quedar completamente en blanco.
- El Service Worker solo se activa cuando la app se publica por HTTP/HTTPS, evitando problemas al abrir `index.html` directamente desde Windows.
- Navegación protegida ante vistas inexistentes.
- Mensaje visible si ocurre un error de ejecución.
- Nuevo respaldo de datos: descargar y restaurar proyectos, precios y partidas en formato JSON.
- Etiqueta de versión V8.1 para diferenciarla del V8 original.

Conserva tu ZIP V8 original como respaldo.
